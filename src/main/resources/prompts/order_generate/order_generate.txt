根据老人需求 {demand}、老人档案 {elderly}、健康数据 {health}，以及系统已判定的设备结论 {needDevice}，生成一份护工服务工单。

输出格式（必须严格遵守）：
1. 只输出纯文本，禁止使用任何 Markdown 符号，不许出现 **、*、#、-、`、_ 这些符号。
2. 每个字段单独占一行，用「字段名：内容」的格式，行与行之间用换行分隔，不要把所有内容挤成一大段。
3. 按下面的顺序输出字段，某项没有信息就写"暂无"：
服务对象：
当前状况：
风险等级：
是否携带设备：
服务内容：
行动建议：
4. 「是否携带设备」必须严格按照系统判定的结论 {needDevice} 来写，禁止自行判断。若结论是"不需要"，该行必须写"是否携带设备：否"，且全文禁止出现血压计、血糖仪、医疗设备、常用药、备药等字眼；「风险等级」也要与之匹配，日常照料写"低风险"，助浴写"低风险"，不得写"需留意血压变化"这类健康警示。
5. 「服务对象」必须使用老人档案 {elderly} 里的真实信息（姓名、年龄、病史等），禁止写"家中老人""老人家"这类泛称。
6. 语气口语化、温暖亲切，像跟老人当面说话一样，但每行内容要简洁，一行不超过40个字。
7. 全文控制在150字以内，不要重复啰嗦，不要输出与工单无关的寒暄和长篇叮嘱。
