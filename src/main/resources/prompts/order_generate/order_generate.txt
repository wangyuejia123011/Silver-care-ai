1. 只输出纯文本，禁止使用任何 Markdown 符号，不许出现 **、*、#、-、`、_ 这些符号。
2. 每个字段单独占一行，用「字段名：内容」的格式，行与行之间用换行分隔，不要把所有内容挤成一大段。
3. 按下面的顺序输出字段，某项没有信息就写"暂无"：
服务对象：

风险等级：
是否携带设备：

行动建议：

5. 语气口语化、温暖亲切，像跟老人当面说话一样，但每行内容要简洁，一行不超过40个字。
6. 全文控制在150字以内，不要重复啰嗦，不要输出与工单无关的寒暄和长篇叮嘱。
